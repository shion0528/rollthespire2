# RolltheSpire2 性能优化分支

当前正式版本：**1.3.5-resource.17**。基于 [FalseOcean/rollthespire2](https://github.com/FalseOcean/rollthespire2) 开发，保留原作者归属及 Mozilla Public License 2.0。

这是可独立分发的纯Mod：运行包只有 `RolltheSpire2.dll` 与 `RolltheSpire2.json`，沿用游戏自带环境，没有安装器、CUDA或额外Python运行环境。

## 使用与环境

目标为Windows x64、游戏0.111.0；复制Mod ZIP内的 `RolltheSpire2` 文件夹到 `<游戏目录>/mods/`。先正常退出游戏再替换文件。

打开设置中的计算资源与搜索优化。七个优化开关默认允许启用，执行器只在条件、版本和硬件门槛满足时使用。CPU四路预筛需要AVX2；不支持时保留标量路径。GPU不可用或条件不适用时采用既有兼容路径，具体范围见兼容性说明。

## 现有优化

前8字符哈希缓存、精确抽取区间、叶药按需计算、成本与淘汰率筛选、商店逐店筛选和随机推进延迟、CPU四路必要条件预筛、GPU候选组内汇总、适用路线双窗口、提前状态头回读与稀疏预取、战斗奖励固定池准备、同候选开局推演复用、Boss条件按需预测，以及后台异步结果接收。

完整范围、关闭和回退规则见 [现有优化](docs/现有优化.md)。这些机制不保证所有预设同幅加速，也不能把各项历史百分比相加。

## 测速与通用预设

- [测速报告](docs/优化测速.md)：历史34场景全量对照、后续负项复测和当前17对16增量。
- [测试预设](docs/测试预设.md)：35个明确场景定义，区分供选、实际选择、领取顺序、最终诅咒、玩家槽位和后续观测。
- [测试配置与方法](docs/测试配置与方法.md)：机器、图形后端、帧率、消费者、预热、计数边界及局限。
- `benchmarks/measurements.json`：260条原始计时输入及各自对照定义。
- `benchmarks/presets.json`：完整有效Query、通用释义和各套件预算。
- `benchmarks/优化测速汇总.xlsx`：带计算公式的数据表。

全量表测试的是resource.15对上游v1.3.5，不是resource.17全量复测。后续存在负收益与波动，原样保留。当前17相对16的两个已测场景均速比分别约+44.48%和+3.99%，不能据此推算17相对原版的全量收益。
