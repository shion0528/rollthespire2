# 测试预设的通用定义

场景编号是测速表与输入数据的连接键。名称已改为条件含义；旧私有名称仅在JSON的legacyAliases中保留映射。英文模型ID用于消除翻译差异。所有条件针对同一种子，分别按其预测语义判断。开局领取及其绑定的后续条件需要存在合法开局路线；独立事件和标准商店分别假定进入相应事件或商店，不构成一条实际游玩路线的可达性证明。

未指定的槽位或目标表示不限制，不能读成“没有该物品”。供选包含不等于固定牌位，也不自动等于实际拿取。路线选择策略另行说明。

## 共同语义

- OpeningRoute 是所选并领取的 Neow 路线；Players[].Offers 是初始供选包含条件。两者不可互换。
- Bones 二遗物结果身份按包含目标比较。指定1个目标保留另一遗物自由；指定2个不同目标占满结果。AnyOrder 允许任一领取顺序存在一条同时满足全部后续条件的路线；不是固定顺序，也不要求两种顺序均成功。
- 观察实际二项输出，按无序多重集包含非空目标。1个目标只要求二项中有一项，另一个自由；2个目标填满二项。相同目标写两次必须有两份。
- 万花筒供选条件。单目标可在任一组；双目标必须在不同的独立组中分别可供选择。AnyOrder 不限定哪个目标在哪组。AllowDuplicateOutputs=true 保留目标重复次数，不额外要求重复。ExactOrder 使用两个位置的 KaleidoscopePositionalSlots，null 为该组无目标限制。
- 这是路线策略，与供选包含条件分开：按所写目标实际选择可选牌，未写目标的可跳过组按策略跳过。不得把万花筒的 Query 条件直接重述成仅验证最终获得的牌。
- Small Capsule 内部1件遗物在游戏中可跳过；产品路线假定领取并应用效果。Large Capsule 内部2件遗物强制领取；无序身份匹配不改变实际效果执行顺序。
- 在所选 Bones 路线两件遗物及相关效果执行之后的最终诅咒。不是独立初始诅咒首抽。
- 初始个人 RelicGrabBag 序列；Common/Uncommon/Rare 从 Front、Shop 从 Back。FirstN=1 等价该序列首项，不是第一次实际获得稀有遗物，也不是开局胶囊消耗后的剩余袋首项。
- Count=N 观察前 N 场默认普通战斗；Slots 的位置是战斗序号。Ordered 的非空目标要求对应战斗供选包含，null 位置不限牌身份；不要求拿取。Unordered 对目标与不同战斗做一对一分配。
- EventResultConditions 只预测对应事件/选项已经发生时的事件局部结果；不会证明事件出现、房间路线可达或实际选择。Fake Merchant 是库存供选包含，不是购买。变牌事件另外要求合法初始 Basic 目标及固定局部池/RNG 前提，统计 raw replacement 身份。
- 拥有者 pristine Shops 流上连续成功的标准普通商店初始供售槽；不包含购买、补货等额外消耗，也不证明能走到这些商店。Ordered 序列按商店序号绑定；固定逐店表述可与有序序列表达同一条件。
